# Neutral-Carrier Recovery, 1809–1811 — replication code

Analysis scripts for "The Neutral-Carrier Recovery, 1809–1811: Cotton, Dyewoods,
and the Reorientation of the American Baltic Trade."

## Data

The scripts expect the STRO 2.0 data package (Sound Toll Registers Online,
https://www.soundtoll.nl) as semicolon-separated CSVs in `data/`:

- `data/customs_entries.csv` — `ce_id; day; month; year; ...`
- `data/masters.csv` — `ce_id; firstName; ...; lastName; domicile`
- `data/cargoes_regs.csv` — `ce_id; commodity`
- `data/departure.csv`, `data/destination.csv` — `ce_id; departure/destination`

The 466 MB data package is not redistributed here. `us_domicile_dictionary.csv`
(the hand-built captain-domicile normalization used by the captain tests) is
included.

## Scripts

| Script | Produces |
|---|---|
| `analysis/identify_us.py` | Tiered US-voyage identification (certain/probable/ambiguous) from captain domicile |
| `analysis/boom_deepdive.py` | Pooled cargo mix, Tønningen check, captain continuity, direction structure |
| `analysis/boom_cargo_direction.py` | Direction-stratified cargo mix |
| `analysis/boom_captain_tests.py` | Turnover baselines, round-trip appearance, 1812–1815 reappearance |
| `analysis/v10_verification.py` | **All manuscript v10 numbers, computed fresh**: three-leg Kitagawa decomposition, Wilson CIs, Stokf. audit, indigo sensitivity, fuzzy captain matching, 1807 audit |

Run from the repository root, e.g.:

```
python3 analysis/v10_verification.py
```

Note: script filenames retain the working title "boom" for continuity; the
paper uses "recovery" throughout.

## Key measurement choices (v10)

- **Certain tier** = Danish clerk's "i America" annotation on the captain's
  *domicile* field only (not the departure port).
- **Direction** from departure/destination port fields; three legs: merged
  American outbound (strict US→Europe + American-origin *Østersøen*),
  homeward (Europe→US), intra-European.
- **Cargo categories**: naval stores (incl. bar iron), US domestic produce
  (cotton, rice, tobacco, rum), true re-exports (coffee, sugar, tea, pepper,
  **indigo**), dyewoods (incl. *Stokf. holt*), ballast.
- Every percentage in the paper is generated by these scripts; no hand-entered
  figures.
